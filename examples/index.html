生成 DOCX

标题 / 富文本 / 列表 / 表格 / 引用 / 代码块 / 分页符，全部走 jsonToDocx。

生成 XLSX

多工作表 / 合并单元格 / 冻结窗格 / 公式 / 数字格式 / 样式 / 超链接 / 批注，全部走 jsonToXlsx。

生成 PDF

文本 / 标题 / 表格 / 矩形 / 线段 / 分页，全部走 jsonToPdf。 PDF 标准 14 字体不含中文字形，上传 TTF/OTF 后示例自动切换为中文。
